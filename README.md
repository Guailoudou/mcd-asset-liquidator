# 麦麦资产清算官 🍔⏳

> **McD Asset Liquidator** —— 你的麦麦资产正在悄悄死亡。
> 每一张券都有到期日，每一个积分都有清零日，但没有任何一个界面把它们放在一起告诉你"先处理哪个"。
>
> 这个 Skill 做一件事：**扫全账户 → 算死亡时间 → 按损失排序 → 给出照做就行的清算计划。**

基于[麦当劳中国官方 MCP 服务](https://open.mcd.cn/mcp)开发，参赛作品（麦当劳程序员创意开发大赛）。

## 它解决什么问题

你有没有过这些时刻：

- 想起某张券时，它已经过期了 🗑️
- 积分攒了一年，年底发现清零了 💸
- 麦麦商城积分换的券躺在订单里忘了核销 😇
- 麦麦省的领券窗口关了，才想起来"哦，那里有张券" ⏰

这些时钟各自滴答，分散在麦当劳 App 的五六个页面里。**麦麦资产清算官**把它们集中到一张清单上，并直接告诉你：**未来 7 天内有 ¥47.8 的资产正在死亡，今天这顿饭先吃掉这张 ¥13.9 的。**

## 安装方法

### 1. 获取麦当劳 MCP Token

1. 打开 https://open.mcd.cn/mcp ，手机号登录
2. 进入「控制台」→「激活」→ 同意服务协议
3. 复制 Token，设置为环境变量：

```bash
export MCD_MCP_TOKEN="你的Token"
```

### 2. 配置 MCP

将 `mcp-config.example.json` 内容加入你的 Agent 宿主（Claude Code / OpenClaw 等）的 MCP 配置。Token 通过 `${MCD_MCP_TOKEN}` 环境变量注入，**不要写进任何会被提交的文件**。

### 3. 装载本 Skill

把本仓库放进你的 Agent Skills 目录（如 `~/.claude/skills/` 或 OpenClaw 的 skills 目录），对 Agent 说：

> "帮我清算一下麦麦资产"

## 设计亮点

1. **蓝海定位**：别人都在做"怎么省钱点餐"，我们做"别让已拥有的资产白白死掉"——不花一分钱，纯止损。
2. **损失速度排序**：`损失价值 ÷ 剩余天数`，比单纯按到期日排序更贴近真实决策。
3. **含当天计算**：当天到期的券是 P0 中的 P0，算天数含当天，不玩"还剩 0.4 天"的文字游戏。
4. **确认式写入**：读取随意，领券/兑换必须用户逐次确认，绝不未经同意花你的积分。
